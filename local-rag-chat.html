Interactive Demo · Client-Side RAG

A retrieval-augmented chatbot that runs entirely
inside this browser tab.

Embedding model, vector search, and a small instruction-tuned language model all execute on-device via Transformers.js + ONNX Runtime — no backend, no API key, nothing leaves your machine. Ask it about my experience, and watch the pipeline trace on the right show exactly what it's doing.

● 100% client-side ● zero API calls ● WebGPU / WASM ● all-MiniLM-L6-v2 embeddings ● SmolLM2 instruct LLM ● hybrid dense + lexical rerank

Architecture: chunking → MiniLM embeddings → cosine similarity → lexical rerank → context injection → SmolLM2 generation, all inside a dedicated Web Worker via Transformers.js / ONNX Runtime Web, so the UI thread never blocks. First load downloads roughly 100–400MB of model weights depending on the model you pick, cached by the browser afterward — fully offline from then on.
